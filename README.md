# Simple Calculator

A fully functional, interactive calculator built with HTML, CSS, and JavaScript.

## Features

- **Basic Arithmetic Operations**: Addition, Subtraction, Multiplication, and Division
- **Beautiful UI**: Modern gradient background with a clean, responsive design
- **Real-time Display**: Updates display as you input numbers
- **Decimal Support**: Perform calculations with decimal numbers
- **Clear Button**: Reset calculator with the "C" button
- **Error Handling**: Division by zero protection shows "Error"
- **Smooth Animations**: Hover effects and button animations

## How to Use

1. Open `index.html` in your web browser
2. Click on numbers to enter values
3. Click an operator (+, -, *, /)
4. Enter another number
5. Click "=" to see the result
6. Click "C" to clear and start over

## File Structure

- `index.html` - Complete calculator with embedded HTML, CSS, and JavaScript
